# Kirti - Personal Portfolio

A modern, premium personal portfolio website built to showcase my background in Software Engineering, AI/ML, and Full-Stack Development.

Live Preview: [https://portfolio-ivory-ten-24.vercel.app/](https://portfolio-ivory-ten-24.vercel.app/)

## 🚀 Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Theme**: Light & Dark mode support via `next-themes`

## ✨ Features

- **Modern Glassmorphism UI**: Beautiful frosted glass effects, subtle gradients, and soft shadows.
- **Dark Mode**: Fully implemented premium dark theme that toggles seamlessly.
- **Scroll Animations**: Smooth reveal animations powered by Framer Motion.
- **Responsive Design**: Flawless experience across mobile, tablet, and desktop devices.
- **Type-Safe Data Layer**: Easy to update portfolio content via `lib/data.ts`.
- **SEO Optimized**: Pre-configured metadata and OpenGraph tags for better search engine visibility.

## 💻 Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 🛠️ Editing Content

All portfolio content is stored centrally in `lib/data.ts`. You can easily update your projects, skills, experience, and education by modifying this single file without touching the UI components.
